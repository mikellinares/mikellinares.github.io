# Apps de Mikel Linares

Web pública de mis apps para Android: https://mikellinares.github.io/

- `index.html`: inicio (sobre mí, apps y contacto).
- `gosignal/`: página de GoSignal.
- `gosignal/privacidad/`: política de privacidad de GoSignal. **Esta URL está registrada en Google Play: no la cambies de sitio.**
- `assets/`: estilos e iconos.

Se publica con GitHub Pages desde la rama `main` (carpeta raíz).
